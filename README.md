## 🌟 Features Overview

- **Interactive AI/ML Intelligence Lab**:
  - **Linear Regression & Loss Lab**: Real-time Ordinary Least Squares (OLS) fitting with live MSE, RMSE, and $R^2$ scores, interactive scatter plot, and custom input inference predictor.
  - **2D Classification & KNN Visualizer**: Interactive 2D coordinate plane with real-time Euclidean distance queries, custom data point placement, and majority voting.
  - **EDA & Feature Preprocessing Pipeline**: Interactive missing value imputation (Mean/Median), outlier capping (IQR filter), and feature scaling (StandardScaler / MinMaxScaler).
  - **Neural Activation Functions & Perceptron Lab**: Live neuron summation and activation curve plotting for **ReLU**, **Sigmoid**, **Tanh**, and **Leaky ReLU**.

- **Featured Projects with Interactive Simulators**:
  - **Innovative E-Learning Platform** (*HTML5, CSS3, JavaScript, PHP, SQL*): Includes interactive course catalog, role-based auth concepts, progress tracking, normalized 3NF database schema, and live enrollment simulation.
  - **AI/ML Predictive & EDA Intelligence Lab** (*Python, Data Preprocessing, Supervised/Unsupervised Learning*).
  - **Relational Database & Student Analytics Engine** (*SQL, Database Normalization, Index Optimization*) with an interactive SQL query runner.

- **Interactive AI Assistant ("Pratik's AI Agent")**:
  - Floating virtual assistant in the bottom-right corner to answer recruiter inquiries regarding skills, projects, background, and contact info.

- **Executive ATS-Standard Resume Viewer**:
  - Formatted ATS-compliant document layout with single-click **Print / Save as PDF** and **Copy Plain Text** options.

- **Education & Verified Certifications**:
  - Details for MSc Computer Science (Pursuing), BCS, HSC, and SSC.
  - Interactive credential modals for **Python Programming Certification** and **Salesforce Certification (ExcelR)**.

- **Direct Recruiter Connect**:

## 🚀 Getting Started Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Pratikgole96k/PortFolio.git
   cd PortFolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open your browser at `http://localhost:5173` or `http://localhost:3000`.

4. **Build for production**:
   ```bash
   npm run build
   ```

5. **Preview production build**:
   ```bash
   npm run preview
   ```
